# Business Context

This repository simulates a supply chain analytics environment where planners need to identify inventory risk and review replenishment recommendations.

## Stakeholders

- Supply chain planner
- Inventory manager
- Operations leader
- Analytics engineer
- Data scientist

## Decisions Supported

- Which product-location pairs are at stockout risk?
- Which recommendations require human approval?
- Which KPIs support a recommendation?
- Which scenario assumptions produced the recommendation?
